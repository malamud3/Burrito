# Burrito

סביבת מחקר להשוואת חקירת פונקציות בגישה קלאסית ובמסלול רנאטו סאיג — React + Vite.

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח  → http://localhost:5173
npm run build    # בנייה לפרודקשן (dist/)
npm test         # בדיקות יחידה + בדיקת זרימה מלאה
```

## מסלולי הפעילות

המשתתפים מקבלים אוטומטית אחד משני מסלולים לחקירת אותה פונקציה רציונלית:

* **מסלול קלאסי** — שאלות מתמטיות ישירות על תחום ההגדרה, קיצון, אסימפטוטות, חיתוכים, תחומי עלייה/ירידה וגרף.
* **מסלול רנאטו סאיג** — ארבעה שלבים של חקירה מונחית בשאלות חשיבה חישובית, טבלת סימנים והתנהגות הפונקציה, ושרטוט.

## רצף התוכן המחקרי

1. **בוחן מקדים משותף**, לפני הצגת המסלול: עשר אותן שאלות על פונקציה מקבילה `h(x) = x² / (x² − 8x + 15)`, ללא רמזים או כלי שרטוט.
2. **פעילות למידה** על `f(x) = x² / (x² − 4x + 3)`: מסלול קלאסי (שאלות ישירות) או מסלול רנאטו סאיג (ארבע כרטיסיות וטבלת סימנים).
3. **בוחן העברה משותף**: אותן עשר שאלות על פונקציה חדשה `g(x) = x² / (x² − 6x + 8)`, ללא רמזים או כלי עזר.

שני המסלולים משתמשים באותן מטרות מתמטיות ובאותם ארבעה רמזים לפי צורך. בשניהם יש 30 דקות לחלק הלמידה, דף טיוטה, אותו כלי שרטוט דיגיטלי, ואותה מדיניות עזרה מהמנחה: הבהרה טכנית בלבד ללא רמזים מתמטיים. טיימר הלמידה מתחיל רק אחרי הגשת הבוחן המקדים; עם תום 30 דקות עוברים לבוחן ההעברה. הבוחנים המקדים והמסכם אינם מוגבלים בזמן, והמדידה נרשמת בנפרד. ההבדל המתוכנן הוא אופן ארגון הלמידה (שאלות ישירות לעומת כרטיסיות ותבנית טבלה); כלי הגרף והנחיות העזרה אינם ייחודיים לתנאי אחד.

הפונקציות בבוחנים תוכננו כמקבילות מבנית, אך עדיין לא עברו כיול אמפירי של שקילות הקושי; יש לבדוק זאת בפיילוט לפני הסקת מסקנות מהשוואת ציונים.

הקצאה מתבצעת אוטומטית בבלוקים אקראיים של ארבעה משתתפים (שניים בכל תנאי), ונרשמים מספר ההקצאה, הבלוק ושיטת ההקצאה. קוד משתתף שכבר הוקצה נדחה כדי למנוע הקצאה חוזרת. מנגנון זה נשמר ב-`localStorage` ולכן מיועד להרצה רציפה באותו מכשיר ובאותו דפדפן; הוא אינו מסנכרן בין מכשירים או דפדפנים.

## נתוני מחקר

* אירועי הלוג כוללים מזהה סשן, קוד משתתף, מסלול שהוקצה, פרטי ההקצאה, חותמת זמן וסוג פעולה; לוגים של משתתפים קודמים אינם נמחקים אוטומטית בעת התחלת סשן חדש.
* תשובות הבוחן המקדים, פעילות הלמידה ובוחן ההעברה נשמרות בנפרד ומיוצאות לצד אירועי התחלה והגשה. תשובות חלקיות נשמרות.
* משך הלמידה נמדד מהגשת הבוחן המקדים עד סיום הפעילות או תום הזמן, ולא כולל את הבוחנים.
* לוח החוקר מאפשר לייצא לוגים מצטברים בפורמטי JSON ו-CSV. יש לייצא גיבוי לפני ניקוי נתוני הדפדפן.
* נתונים והקצאות נשמרים מקומית ואינם נשלחים לשרת. הקצאה אקראית זו אינה תחליף לשירות מרכזי, הסתרת הקצאה או ניתוח סטטיסטי; מחיקת נתוני האתר מאפסת גם את רצף ההקצאה.

הניווט בין מסכי הפעילות מבוסס כתובות דרך React Router. תוכן השאלות והנתונים הצפויים של פונקציית רנאטו מוגדרים תחת `src/core/constants/`.
